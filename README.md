# Projeto-UX---Petshop

🐾 Projeto UX — Petshop

📌 Sobre o projeto

Protótipo de uma interface de Petshop, desenvolvido no Figma, com foco em criar uma experiência simples, intuitiva e agradável para usuários que buscam produtos e serviços para seus animais de estimação.

O projeto explora a organização das informações, navegação entre telas e interação com diferentes elementos da interface.

🎯 Objetivo

Desenvolver uma interface de Petshop com navegação intuitiva, facilitando o acesso do usuário a produtos, serviços e informações relacionadas aos cuidados com os pets.

🛠️ Ferramenta

- 🎨 Figma

💡 Principais funcionalidades do protótipo

- 🐶 Navegação pela interface do Petshop
- 🛍️ Exploração de produtos e serviços
- 📋 Acesso a informações relacionadas aos serviços
- 🧭 Navegação entre diferentes telas
- 🔗 Botões interativos direcionados para outras páginas e redes sociais
- 📱 Interface desenvolvida com foco em uma experiência simples e intuitiva

🔗 Integração com redes sociais

Alguns botões presentes no protótipo possuem links externos que direcionam o usuário para outras redes sociais e páginas relacionadas ao Petshop.

📚 Área de estudo

Projeto desenvolvido durante os estudos de UX/UI Design, com foco em prototipação, navegação, interação e experiência do usuário.

«Observação: este projeto é um protótipo desenvolvido no Figma. As funcionalidades e interações apresentadas são representações da experiência de uso e não correspondem a um sistema funcional de Petshop.»
